# 修复与动画验收清单

## 1. 开工前

- [ ] 原始场景、原始模型和最近稳定基线均已保留。
- [ ] 当前工作文件是另存的新版本，不是覆盖用户确认过的基线。
- [ ] 已记录场景单位、Maya 版本、播放范围和帧率。
- [ ] 已明确本轮修复对象和动画允许范围。
- [ ] 已明确需要输出的验收图和停止条件。
- [ ] 已检查当前内存和模型数据量，未重复导入完整 morph。

## 2. 场景和骨架事实

- [ ] 主网格有正确 skinCluster。
- [ ] 蒙皮网格父级、旋转和缩放未被擅自修改。
- [ ] 关键骨链层级已核实。
- [ ] twist 骨没有被误当成主肘/膝。
- [ ] 原始中立姿态来自同一模型的干净数据。
- [ ] 未将整套关节清零。
- [ ] 已记录约束、IK、SDEF、blendShape、Delta Mush 和动画输入连接。
- [ ] 外部 reference、贴图和未知节点已记录。

## 3. 姿态求解

- [ ] 使用世界空间位置和目标。
- [ ] 两段 IK 显式指定 start/middle/end。
- [ ] 目标距离经过可达性检查。
- [ ] 极点不与目标轴共线。
- [ ] 返回结果包含目标是否被钳制。
- [ ] 实际末端误差已读取，而非读取 IK 手柄。
- [ ] 脚底/手掌的世界朝向已单独检查。
- [ ] 修改髋部后，手臂和桌面接触已重新验收。

## 4. 网格和接触区域

- [ ] 人体包围盒尺寸符合当前人物尺度。
- [ ] 脚底没有明显穿地或漂浮。
- [ ] 肩、肘、腕、膝盖、脚踝和袖口完整。
- [ ] 桌面/道具内部顶点计数已记录。
- [ ] 椅面接触通过图像判断，未把计数简单等同于穿插。
- [ ] 网格无异常翻转、变黑、破裂或拉伸。
- [ ] 旧 MMD 大角度弯臂问题已避免或更换模型验证。

## 5. 四向图像

- [ ] 正面。
- [ ] 左侧。
- [ ] 右侧。
- [ ] 俯视。
- [ ] 人物完整入镜，头顶和脚底没有被裁掉。
- [ ] 单人图中其他人物已隔离，桌椅和接触道具仍可见。
- [ ] 相机切换使用实际创建返回名。
- [ ] 使用当前可见 modelPanel 和 lookThru。
- [ ] 不同视角图像哈希不同，且内容确实不同。
- [ ] 图片不是旧目录中的缓存或上一版文件。

## 6. 保存后回读

- [ ] 保存新版本后重新打开。
- [ ] 主网格、骨架和观察相机数量一致。
- [ ] 关节目标和世界姿态重新计算。
- [ ] 碰撞和尺度指标重新计算。
- [ ] 回读结果与保存前一致。
- [ ] 当前工作场景没有被诊断脚本意外覆盖。

## 7. 动画

- [ ] 动画基准来自已验收姿态，不是零旋转。
- [ ] 头部视线目标与剧情一致。
- [ ] 手部动作与人物模型能力匹配。
- [ ] 没有未经允许的嘴型、手指、躯干或腿部动画。
- [ ] 没有统一模板转头、root 摇摆或随机动作。
- [ ] 道具数量、绑定、接触和切镜连续性已检查。
- [ ] 短段已检查切镜、视线、动作和穿插。
- [ ] 用户确认前没有渲染全片。

## 8. 相机与渲染

- [ ] 每镜读取主体、听者、前景、动作和运镜。
- [ ] 180° 轴线有记录并通过短段检查。
- [ ] 运镜起止值真实不同且对应首末帧。
- [ ] 正式相机与观察相机分组明确。
- [ ] 渲染时实际使用目标相机，不存在静默回退。
- [ ] 每镜输出文件数等于 `end-start+1`。
- [ ] 总帧数不匹配时没有通过切片掩盖。
- [ ] 输出目录为当前版本新目录。
- [ ] 帧率、分辨率、字幕、音轨和编码参数与确认一致。
- [ ] 编码后检查首末帧、切点、关键动作和音画同步。

## 9. 停止并回退的条件

出现任一情况，停止在当前版本继续叠补丁：

- [ ] 无法解释局部角与世界姿态为何不一致。
- [ ] 蒙皮网格父级或坐标系已被破坏。
- [ ] 同一部位连续多轮靠猜角度修补。
- [ ] 新一轮修复引入更大的扭曲或穿插。
- [ ] 图片重复、相机切换失效或保存后数据丢失。
- [ ] 旧模型在目标动作下持续破袖。
- [ ] 需要超出用户允许的身体动作范围才能继续。

回到最近干净基线，缩小动作范围或更换已验证模型，并记录原因。

## 11. 最终完成定义

“修复完成”必须意味着：工作场景可编辑、目标姿态实际生效、网格可接受、四视图可核查、保存后回读一致、动画范围未越界、遗留风险已写明。

任何一项缺失，都应报告为“部分完成”或“待验收”，而不是“全部完成”。
